# Plan: Guard MainWindowContent with Authentication

## Goal
Guard `MainWindowContent` (line 30-31 in `MainWindow.tsx`) so only authenticated users can view the content. Unauthenticated users will see a login modal overlay.

## Current State
- `useAuth` hook provides `isLoggedIn`, `user`, `login`, `logout`
- `LoginModal` component exists in `src/components/auth/LoginModal.tsx`
- `MainWindowContent` renders routes for dashboard, entities, etc.

## Implementation Steps

### Step 1: Create AuthGuard Component
**File:** `src/components/auth/AuthGuard.tsx`

Create a new component that:
- Accepts `children` as content to render when authenticated
- Uses `useAuth()` to check `isLoggedIn`
- Shows `LoginModal` overlay when not authenticated
- The modal should auto-open (controlled state)
- On login success, close modal and show content

```tsx
interface AuthGuardProps {
  children: React.ReactNode
}

export function AuthGuard({ children }: AuthGuardProps) {
  const { isLoggedIn, login } = useAuth()
  const [loginModalOpen, setLoginModalOpen] = useState(!isLoggedIn)

  const handleLoginSuccess = (userId: string) => {
    login(userId)
    setLoginModalOpen(false)
  }

  return (
    <>
      {isLoggedIn ? children : <div className="..." />} {/* placeholder/loading */}
      <LoginModal
        open={!isLoggedIn || loginModalOpen}
        onOpenChange={setLoginModalOpen}
        onLoginSuccess={handleLoginSuccess}
      />
    </>
  )
}
```

### Step 2: Wrap MainWindowContent with AuthGuard
**File:** `src/components/layout/MainWindow.tsx`

Import `AuthGuard` and wrap `MainWindowContent`:
```tsx
<AuthGuard>
  <MainWindowContent />
</AuthGuard>
```

### Step 3: Verify Loading State
Ensure auth check handles loading state gracefully (useAuth returns `isLoading` from userQuery)

## Design Decisions
- **Login modal auto-opens** when not authenticated (no separate login page needed)
- **No redirect** - modal overlay keeps user in context
- **Uses existing LoginModal** - reuses current auth UI pattern
- **Persists across route changes** - modal stays open until successfully authenticated
